# lilies

A bouquet of pink, tiger and white lilies drawn in coloured ASCII characters. The stems grow, the lilies open, and the whole bouquet turns a full 360 every few seconds.

Built with React (UMD build, no bundler) and a 2D canvas. The bouquet is modelled in simple 3D, drawn to a small offscreen canvas, then each pixel is turned into a character.

## Run it

Open `index.html` in a browser. No build step.

## Things to try

- Tap a lily to read a love quote (18 of them).
- Drag sideways to spin the bouquet.
- Add a name to the URL: `index.html#for-amani` shows `// for amani` under the heading.
